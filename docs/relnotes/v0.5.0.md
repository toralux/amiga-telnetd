Concurrent telnet sessions: up to four clients at once, each with its
own shell and console. Hardware-validated on an A500 (68000,
AmiTCP_NG 4.1.7) with four simultaneous clients.

## Downloads

- `telnetd` - 68000 (stock A500/A2000; also runs on accelerators)
- `telnetd.020` - 68020/030/040/060 accelerators (integer code only, no FPU required). Compile-verified; not yet runtime-tested on accelerated hardware.

## What's new

- Multi-session: up to 4 concurrent telnet clients (MAXSESSIONS option (1-8, default 4)).
  Each session gets its own shell with the full line editor and
  command history.
- Session isolation: input and output are strictly separated - no
  cross-talk between clients.
- A client beyond the limit is refused with a clear message
  ("too many sessions - try again later"); existing sessions are
  unaffected.
- Disconnecting one client retires only that session; the others keep
  working and the hung-up shell ends on its own.
- Freed session slots are reused once the retired session's handles
  have closed.

All v0.4.9 fixes are included.
