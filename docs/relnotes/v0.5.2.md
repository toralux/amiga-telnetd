Maintenance release: fixes an output-buffer accounting bug that could
drop output in edge cases. Hardware-validated on an A500 (68000,
AmiTCP_NG 4.1.7).

## Downloads

- `telnetd` - 68000 (stock A500/A2000; also runs on accelerators)
- `telnetd.020` - 68020/030/040/060 accelerators (integer code only, no FPU required). Compile-verified; not yet runtime-tested on accelerated hardware.

## Fixes

- Budget WRITE output by real expansion: the console translates some
  program bytes into more bytes for the client (a form feed becomes a
  seven-byte clear-and-home). Output is now budgeted by the exact
  translated size instead of a fixed worst case, so no WRITE can
  overrun the buffer reserve - and ordinary text can use the whole
  buffer instead of half of it.

Everything else is unchanged from v0.5.1.
